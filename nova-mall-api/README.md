# novamall-api

NovaMall 积分商城系统的后端服务，基于 Spring Boot 2.7 + MyBatis + MySQL，提供商城前台与后台管理的 REST API。

- 包名：`com.novamall.api`
- 启动方式：`mvn spring-boot:run`（需先准备 MySQL 8 并执行 `src/main/resources/novamall_db_schema.sql`）
- 接口文档：启动后访问 Swagger 页面（springfox）
